# DevOps Lab Assignments

This repository contains practical implementations and lab reports for DevOps course assignments.

## Assignment 1: Git Repository and Branch Management
- **Project**: Python Calculator Utility
- **Topics**: Git 3-Tree Architecture, Branching, Merging, Reset vs. Revert

### Project Guidelines
- All production code resides on `main`.
- All features must be developed on dedicated `feature-*` branches and merged via merge commits.
- Conventional commit conventions are strictly followed (`feat:`, `fix:`, `docs:`).
